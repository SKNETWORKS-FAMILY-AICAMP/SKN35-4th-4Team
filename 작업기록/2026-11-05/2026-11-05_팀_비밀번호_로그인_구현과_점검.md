## 1. 왜 비밀번호를 붙였나

- 3차는 아이디만으로 로그인해서, 아이디를 아는 사람은 누구나 남의 대화 기록을 열 수 있었다.
- 4차는 웹으로 배포하므로 아이디 + 비밀번호로 바꿨다. 아이디 규칙(한글 · 영문 · 숫자 · _ 2~20자)은 3차와 같다.

## 2. 흐름

```text
[가입]                                         [로그인]
아이디 · 비밀번호 · 비밀번호 확인                 아이디 · 비밀번호
        │                                             │
입력 검사: 아이디 규칙 · 6~64자 · 확인 일치 · 중복     users 테이블에서 아이디 찾기
        │                                             │
make_password()                                check_password()
  무작위 소금 + pbkdf2_sha256 100만 번 반복         저장된 소금 · 반복 횟수로 다시 계산해 비교
        │                                             │
TiDB users.password 에 해시만 저장  ─────────▶   일치 → 세션 키 새로 발급 → 로그인
        │                                        틀림 · 없는 아이디 → 같은 안내 문구
세션 키 새로 발급 → 로그인
```

## 3. 만든 것

| 부분 | 담당 | 내용 |
|---|---|---|
| 모델 | ① | `users.User`에 `password` 칸 (`CharField(128)`, `db_default=""`) |
| 마이그레이션 | ① | `users/migrations/0002_user_password.py` (TiDB 반영) |
| 가입 API | ① | `POST /api/users/signup/` → 검사 4가지 → `make_password()` 저장 → 세션 로그인 |
| 로그인 API | ① | `POST /api/users/login/` → `check_password()` 비교 → 세션 로그인 |
| 화면 | ④ | 로그인: 비밀번호 칸 / 가입: 비밀번호 · 확인 칸, 6자 미만 · 확인 불일치는 화면에서 먼저 막음 |

정한 것과 이유

| 결정 | 이유 |
|---|---|
| 원문이 아니라 해시로 저장 | 되돌릴 수 없어서 DB가 새도 원문을 알 수 없음 |
| Django `make_password()` 그대로 | 소금(사람마다 다름)과 100만 번 반복을 알아서 해 줌 |
| `db_default=""` | 이 칸을 모르는 다른 브랜치 코드가 사용자를 넣어도 오류가 안 남 |
| 틀린 비밀번호와 없는 아이디를 같은 문구로 | 남의 아이디가 있는지 떠볼 수 없게 |
| 로그인 · 가입 때 세션 키 새로 발급 | 세션 고정 공격 방지 |

## 4. 전체 점검

| 점검 | 결과 |
|---|---|
| 로그인 전 대화 화면 · API | 로그인 화면으로 (302) · 401 · 403 ✅ |
| CSRF 토큰 없이 로그인 · GET으로 로그인 | 403 · 405 ✅ |
| 가입 검사 5가지 (아이디 규칙 · 띄어쓰기 · 6자 미만 · 확인 불일치 · 중복) | 이유를 알려 주고 막음 ✅ |
| 비밀번호 빈칸 · 틀린 비밀번호 · 없는 아이디 | 같은 안내 ✅ |
| 남의 대화 열기 · 삭제 | 404, 그 대화는 그대로 ✅ |
| DB 저장값 | `pbkdf2_sha256` 해시, 원문 없음 ✅ |

### 찾아서 고친 문제: 응답 시간으로 아이디가 드러남

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 없는 아이디로 로그인 | 486ms | 1189ms |
| 있는 아이디 + 틀린 비밀번호 | 1216ms | 1110ms |

- 있는 아이디일 때만 해시 계산(100만 번)을 해서 0.7초 차이가 났다. 없는 아이디도 미리 만든 가짜 해시로 같은 계산을 하게 맞췄다.

### QA에서 함께 고친 것 (③)

- 배포 이미지 기본값 `DJANGO_DEBUG=False`, `DJANGO_SECRET_KEY`가 없으면 경고, 요청 본문 형식 검사, 질문 길이 20,000자 제한.
