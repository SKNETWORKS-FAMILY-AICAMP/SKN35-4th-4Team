## ④가 한 작업

### 1. 발표자료 재구성

청중이 3차와 같아서, **3차와 같은 부분은 빼고 4차에서 바뀐 것만** 보여 주도록 다시 짰다.

| 순서 | 슬라이드 |
|---|---|
| 1 ~ 3 | 팀 소개 → 표지 → 발표 순서 |
| 4 ~ 6 | 3차 보완점 → 해결 방향(배포 설계 · 평가 범위) → 3차 → 4차 바뀐 것만 |
| 7 ~ 10 | 배포 구성 → Django API(팀 의견으로 추가) → 질문 분류 → 진행 표시 |
| 11 | 시연 (지루하지 않게 기술 소개 바로 뒤, 중간에) |
| 12 ~ 15 | 결과 정리 → 지표별 비교 → RAG 평가 → 마무리 |

- 뺀 것: 3차 그대로인 RAG 데이터 · LLM 구조 · 기술 스택 · 주요 기능, 회고, 시연 캡처
- 지표마다 설명을 붙였다 (공통 기준 · 실행 기준 · 최종 검증 · 1회차 검증)
- RAGAS는 "3차는 코드 변환만 평가했고, 4차는 RAG까지 평가했다"로 표현했다
- 모션: 숫자 올라가기 · 막대 차오르기 · 진행 단계가 한 줄씩 쌓이기 · 카드 순서대로 올라오기
- 함께 만든 것: 15분 발표 대본, 예상 질문 21개와 답변 (각각 PDF)

### 2. 발표자료 PDF

- 슬라이드 앱의 PDF 내보내기는 애니메이션 시작 전 화면을 찍어서, 막대는 비고 숫자는 0으로 나왔다.

## 겪은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 문서 질문 예제를 보내면 연결 실패 | 테스트하던 로컬 미리보기 서버를 꺼서 화면만 남아 있었음 | 배포 서버에서 확인하기로 함 |
| 재배포했는데 예제가 30개 그대로 | 서버는 14:55 새 파일(예제 60개 · 서랍 코드)을 주고 있었고 브라우저가 예전 JS를 씀 | Ctrl+F5 · 시크릿 창 안내를 팀 채팅에 공유 |
| 슬라이드 http 링크가 눌리지 않을 수 있음 | 슬라이드 형식은 https 링크만 허용, 배포 서버는 https 미지원 | http로 두고 시연은 주소창 · 미리 연 탭으로 |
| 편집기에서 저장하면 카드 모션이 사라짐 | 모션은 위치를 고정한 요소에만 허용 | 카드를 슬라이드에 직접 고정 |
| 슬라이드 아이콘이 이상하게 보임 | 지원하지 않는 아이콘 이름 | 아이콘 삭제 |
| README 초안이 개인 저장소 형식을 다 못 따라감 | 참고 README를 앞부분만 읽음 | 두 저장소를 끝까지 읽고 평가 문서를 만든 뒤 다시 구성 |
